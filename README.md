# Travel List - WIP (Work In Progress)

**Travel List** is a small application designed to help you track the countries and cities you've visited, while also assisting in planning your future trips. The app features an interactive map for visualizing your past trips and planning your next adventures.

## Features

- Track countries and cities you've visited on your personal dashboard
- Plan your upcoming trips
- Interactive map for visualizing past and future travels
- Simple and user-friendly interface

## Technology Stack

- **Frontend**: React
- **Backend**: Node.js/Express
- **Database**: PostgreSQL
- **Map Integration**: to be defined
